## Goal

Create a subdomain: `blog.shoyeb.asia`

---
## DNS Configuration

Cloudflare → DNS → Add Record

| Type  | Name | Target      |
| ----- | ---- | ----------- |
| CNAME | blog | shoyeb.asia |

![[domain8.png|697]]

![[domain14.png]]

Now just add the `blog.shoyeb.asia` subdomain to GitHub Pages. If it doesn't work, delete the GitHub `CNAME` file, wait 5 minutes, and boom — it should work! 

Now both `blog.shoyeb.asia` and `shoyeb.asia/blog` are working.

![[domain15.png]]

## Redirect Rule (Optional)

Suppose I don't want to expose `shoyeb.asia` directly, or I want to redirect another domain to a specific URL. I can also use a Redirect Rule to redirect an existing subdomain, such as `info.shoyeb.asia`, to `shoyeb.asia`  or `shoyeb.is-a.dev` to `shoyeb.asia`.

Cloudflare → Rules → Redirect Rules → Create Rule

![[domain10.png]]

![[domain11.png]]

Before using `info.shoyeb.asia`, make sure to add a DNS record.

![[domain16.png]]

![[domain12.png]]

Type `Static` if it is a specific URL like `https://mrtemp70.github.io/info`

![[domain9.png]]

***or,***

Type `Dynamic` if it is not a specific URL and may include multiple paths like `shoyeb.asia/test1` or `shoyeb.asia/test2`.

Expression:

```text
concat("https://mrtemp70.github.io", http.request.uri.path)
```
