## 1. Add Your Domain
- Go to: https://mailtrap.io/domains
- Add your domain (e.g. shoyeb.asia).

## 2. Verify DNS
- Mailtrap will provide the required DNS records.
- Add those records to your DNS provider (e.g. Cloudflare).
- Return to Mailtrap and click Verify DNS.

## 3. Create an API Token
- Open Transactional Stream.
- Create a new API Token.
- Important: The token is only shown once. You can regenerate it later, but you cannot view it again.
- Free plan limits:
  - 150 emails/day
  - 4,000 emails/month

## 4. Use SMTP in ASP.NET

In .NET 10, SmtpClient is available without installing any NuGet package.

```csharp
using System.Net;
using System.Net.Mail;

using var client = new SmtpClient("live.smtp.mailtrap.io", 587)
{
    Credentials = new NetworkCredential("api", "YOUR_API_TOKEN"),
    EnableSsl = true
};

client.Send(
    "info@shoyeb.asia",
    "msashoyeb@gmail.com",
    "From Bhaiya",
    "This is my new custom mail server. I am no longer using Gmail."
);

Console.WriteLine("Sent");
```

## Notes
- SMTP Host: live.smtp.mailtrap.io
- Port: 587
- Username: api
- Password: Your Mailtrap API token
- SSL: Enabled
- Replace YOUR_API_TOKEN with your generated token.


---

> [!info] 
>  **Mailtrap** is only used to **send test emails** or emails like **password reset emails**. It works as an **SMTP (Simple Mail Transfer Protocol)** server, which is used for sending emails.
> 
> To **receive emails**, you can use **Zoho Mail (free plan)**, another email provider, or **Cloudflare Email Routing**. For example, emails sent to **[info@shoyeb.asia](mailto:info@shoyeb.asia)** can be automatically forwarded to **[msa@gmail.com](mailto:msa@gmail.com)**.
> 
> Receiving emails uses **POP3 (Post Office Protocol version 3)** or **IMAP (Internet Message Access Protocol)**, which are email retrieval protocols. 
### What Mailtrap is designed for

Mailtrap is mainly an **email delivery and testing platform**. Its focus is:

- ✅ Sending transactional emails (password resets, verification emails, invoices, etc.)
- ✅ Testing emails safely during development
- ✅ Email analytics and deliverability

It is **not designed to be a full email hosting provider** like Zoho Mail or Google Workspace.
