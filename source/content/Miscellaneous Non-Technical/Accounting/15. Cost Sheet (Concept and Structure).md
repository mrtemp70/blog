## 🎯 বাস্তব জীবনে Cost Sheet কেন প্রয়োজন? (Why We Need a Cost Sheet?)

ধরুন, আপনি একটি জুতো তৈরির কারখানা বা কোম্পানি খোলেন। আপনি যদি জানতে চান ১ জোড়া জুতো বানাতে আপনার মোট কত টাকা খরচ হচ্ছে এবং জুতোটি বাজারে কত টাকায় বিক্রি করা উচিত, তবে কস্ট শিট আপনাকে সাহায্য করবে। 

এটি ব্যবহার করে একজন সিইও (CEO) বা ম্যানেজার নিচের ৩টি বড় সুবিধা পান:
1. **টোটাল কস্ট নির্ণয় (Total Cost Calculation):** পণ্যটি তৈরিতে কাঁচামাল, শ্রমিকের মজুরি এবং ফ্যাক্টরির ভাড়া মিলিয়ে মোট কত টাকা খরচ হলো তা জানা যায়।
2. **বিক্রয় মূল্য নির্ধারণ (Fixing Selling Price):** মোট খরচের সাথে নিজের কাঙ্ক্ষিত লাভ (Profit) যোগ করে পণ্যের সঠিক দাম নির্ধারণ করা সহজ হয়।
3. **অপচয় ও খরচ নিয়ন্ত্রণ (Cost Control):** কোন খাতের খরচ অস্বাভাবিকভাবে বাড়ছে (যেমন- কাঁচামালের দাম নাকি ফ্যাক্টরির বিদ্যুৎ বিল) তা সহজেই সনাক্ত করে অপচয় কমানো যায়।

## 📊 কস্ট শিটের একটি আদর্শ ছক (Standard Cost Sheet Format)

হিসাববিজ্ঞানের নিয়ম অনুযায়ী একটি পূর্ণাঙ্গ কস্ট শিট ক্রমান্বয়ে নিচের ৪টি ধাপে হিসাব করা হয়:

| Particulars (বিবরণ) | Amount ($) | Amount ($) | Explanation (সহজ বাংলা অর্থ) |
| :--- | :---: | :---: | :--- |
| **Direct Materials Used** (সরাসরি ব্যবহৃত কাঁচামাল) | XXX | | জুতো তৈরির মূল চামড়া বা কাপড়ের খরচ। |
| (+) **Direct Labor / Wages** (সরাসরি মজুরি) | XXX | | যে কারিগর সরাসরি জুতোটি বানিয়েছেন তার মজুরি। |
| (+) **Direct Expenses** (সরাসরি অন্যান্য খরচ) | XXX | | এই মডেলের জন্য বিশেষ কোনো নকশা বা ফিজ। |
| **🏆 PRIME COST (মুখ্য ব্যয়)** | | **XXX** | **মূল উৎপাদন শুরুর আগের প্রাথমিক খরচ (১ম ধাপ)।** |
| | | | |
| (+) **Factory / Manufacturing Overheads** | | XXX | ফ্যাক্টরির ভাড়া, সুতোর খরচ, মেশিনের অবচয় ইত্যাদি। |
| **🏆 WORKS COST / FACTORY COST** | | **XXX** | **ফ্যাক্টরির ভেতরের মোট উৎপাদন খরচ (২য় ধাপ)।** |
| | | | |
| (+) **Office & Administrative Overheads** | | XXX | অফিসের কর্মকর্তাদের বেতন, অফিসের লাইট/ফ্যান বিল। |
| **🏆 COST OF PRODUCTION** | | **XXX** | **অফিসসহ পণ্যটি তৈরি করার মোট খরচ (৩য় ধাপ)।** |
| | | | |
| (+) **Selling & Distribution Overheads** | | XXX | পণ্যের বিজ্ঞাপন খরচ, শোরুমের ভাড়া, ডেলিভারি খরচ। |
| **🏆 TOTAL COST / COST OF SALES** | | **XXX** | **ভোক্তার কাছে পৌঁছানো পর্যন্ত চূড়ান্ত খরচ (৪র্থ ধাপ)।** |
| | | | |
| (+) **Target Profit** (কাঙ্ক্ষিত মুনাফা) | | XXX | আপনি এই পণ্যের ওপর যে পরিমাণ লাভ করতে চান। |
| **💰 SELLING PRICE (বিক্রয় মূল্য)** | | **XXXX** | **বাজারে ক্রেতা এই দামে পণ্যটি কিনবে।** |
