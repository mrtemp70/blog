## Problem Statement 1

Threets Repair Shop was started on May 1 by Erica Threet. A summary of May transactions is presented below:

---
## Transactions List

1. Invested $10,000 cash to start the repair shop.
2. Purchased equipment for $5,000 cash.
3. Paid $500 cash for supplies.
4. Incurred $250 of advertising cost in the Beacon News on account. (Incurred খরচ)
5. Received $6,100 in cash from customers for repair service.
6. Paid $400 cash for May office rent.
7. Withdrew $1,000 cash for personal use.
8. Paid part-time employee salaries $2,000.
9. Paid utility bills $170.
10. Provided repair service on account to customers $750. (কাস্টমারকে ৭৫০ টাকার রিপেয়ার সার্ভিস দিয়েছি অন অ্যাকাউন্ট means বাকিতে)
11. Collected cash of $120 for service billed transaction (10). (৭৫০ ডলারের বিল থেকে ১২০ ডলার কালেক্ট করেছি ক্যাশে)

### Answer: 

**Asset** (Cash + Equipment + Accounts Receivable + Supplies) = **Liabilities** (Accounts Payable) + **Owner’s Equity** (Capital + Revenue − Expenses − Withdrawals)

|    SNO    |   Cash   | Equipment | A/C Rec. | Supply  |  =  | A/C Payable |  Capital  | Revenue  |   Exp.    | Withdraw. |

|     4     |          |           |          |         |  =  |    +250     |           |          |   -250    |           |
|     5     |  +6100   |           |          |         |  =  |             |           |  +6100   |           |           |
|     6     |   -400   |           |          |         |  =  |             |           |          |   -400    |           |
|     7     |  -1000   |           |          |         |  =  |             |           |          |           |   -1000   |

## Final Equation Total (সর্বশেষ মোট যোগফল):

- Assets Total (বাম পাশ): 7150 + 5000 + 630 + 500 = 13280
- Liabilities + Equity Total (ডান পাশ): 250 + 10000 + 6850 - 2820 - 1000 = 13280
